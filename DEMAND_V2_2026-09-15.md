## Metrics and limitations

V2 intent metrics are separated from old generic enquiries. Exclude Trash and marked tests. Within selected dates/filters, each normalized phone's latest V2 answer represents one contact. Qualified means supplied name/phone, use case, intended start within 90 days at enquiry, and known duration. Size uncertainty is allowed. This transparent operational rule is shown in the dashboard; it is not a confirmed sale or independent validation of the phone number.

7/30/90 buckets are cumulative and refer to need at submission. Optional exact start dates override broad timing. Readiness/visit are self-reported. Price acceptance requires an actual positive quote and an accepting response. Counts and size/source/campaign/ad summaries are available with CSV and aggregate JSON export.

Qualified-lead CAC needs manually entered matching ad spend. Denominator uses qualified paid contacts only (explicit paid medium tags). No ad-account integration, invented spend or automatic historical cost backfill. Spend input is not persisted; the export contains the calculation. Clear the input when dates/cohort change.
